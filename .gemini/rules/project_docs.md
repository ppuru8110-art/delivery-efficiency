# プロジェクト技術資料管理 & チャット間共有ルール

1. **技術資料の一括参照**:
   - 新しいセッション・チャットの開始時、AIエージェントは必ずプロジェクトルート直下の `docs/` フォルダ配下にある技術資料を確認し、プロジェクトの現状、要件定義、およびロードマップを同期すること。
     - `docs/README.md`
     - `docs/01_requirements_definition.md`
     - `docs/02_architecture_and_specs.md`
     - `docs/03_implementation_status.md`
     - `docs/04_roadmap_and_upcoming.md`

2. **技術資料の隔離保持**:
   - `docs/` ディレクトリ直下およびサブディレクトリには純粋な技術資料（Markdown形式）のみを保存し、アプリコードや一時ファイルを配置しないこと。

3. **ドキュメントの最新化維持義務**:
   - 機能の実装完了、要件変更、あるいはフェーズの切り替えが行われた際は、必ず対応する `docs/` 配下のドキュメントを最新状態に更新・同期すること。
