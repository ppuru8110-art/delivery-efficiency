# プロジェクト技術資料管理 & チャット間共有ルール

本プロジェクト（ロケットアナライザー）において、AIエージェントは以下を順守してください。

1. **技術資料の参照 & Single Source of Truth**:
   - `docs/README.md`, `01_requirements_definition.md`, `docs/specs/`, `docs/guides/` を正として同期。
   - 単発質問や軽微な修正時は全走査をスキップし省エネを徹底。

2. **iPhone PWA / モバイル操作性基準（配達現場向け絶対要件）**:
   - **フォーム自動ズーム防止**: iOS Safariの自動ズームによるレイアウト崩れを防ぐため、すべての input / select / textarea のフォントサイズは最小 16px（Tailwindの `text-base`）以上を必須とする。
   - **セーフエリア & タップ領域**: 下部固定ナビやボタンは `env(safe-area-inset-bottom)` を必ず確保し、片手操作のため最小 44×44px のタップ領域を維持する。
   - **PWAホワイトアウト耐性**: デプロイ後の古いJSキャッシュに起因するチャンクエラー（ChunkLoadError）発生時は、画面が真っ白のまま停止しないよう自動リロードまたはストレージ再同期の導線を設ける。
   - **デザイン統一**: UIアイコンはすべて導入済みの `lucide-react` を使用し、デザインの統一感を維持する。

3. **オフラインファースト ＆ データ同期設計（現場データ保全）**:
   - 単なる「失敗時のフォールバック」にとどまらず、電波不安定時（地下・エレベーター内等）でも入力データを即座にLocalStorageへ先行保存（UUID採番）し、オンライン復帰時にSupabaseへバックグラウンド同期（Sync Queue）する設計を維持・推進する。
   - データ構造変更時は、端末キャッシュ残存時のクラッシュを防ぐデフォルト値マージを必須とする。

4. **プライバシー & 認証境界（Supabase RLS）**:
   - 配達員の個人情報・日報データを保護するため、匿名利用時であっても端末UUIDまたはSupabase匿名認証（Anonymous Auth）をキーとしたRLS分離を必須とする（`USING (true)` による全開放は厳禁）。

5. **完全0円運用の徹底**:
   - 外部APIは完全無料（APIキー・クレカ不要）のサービス（Open-Meteo等）を最優先とし、従量課金API（Google Maps）利用時は無制限呼び出しを防ぐキャッシュ・フォールバックを常設する。
