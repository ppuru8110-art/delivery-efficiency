# 01. 要件定義書 (Requirements Definition)

## 1. システム概要
- **システム名称**: ロケットアナライザー（Rocket Analyzer / delivery-efficiency）
- **目的**: ロケットナウ（RocketNow）配達パートナー向けに、稼働データ（時間・売上・件数・走行距離・天候・エリア）を簡単記録し、時給換算やエリアごとの効率を可視化・分析することで、最も効率よく楽して稼ぐための自分専用PWAアプリ。
- **実行環境**: iPhone（Safari「ホーム画面に追加」によるPWA起動）
- **ランニングコスト**: **完全無料（0円）**

---

## 2. 対象ユーザー・稼働形態
- **対象者**: 個人事業主のフード・日用品デリバリー配達員（ロケットナウ専属または他社併用）
- **利用シーン**:
  - 配達の合間や稼働終了時の日報入力（片手操作）
  - 稼働前の分析・エリア選定（ダッシュボード確認）
  - 確定申告前の売上・走行距離・経費データの確認

---

## 3. 機能要件

### 【フェーズ1：案3ベース（日報＆アナライザー）】※今回の初回実装対象
1. **簡単日報入力機能**
   - 日時、業務日（深夜日またぎ対応）、稼働開始/終了時間、売上（円）、配達件数、走行距離（km）
   - 配送元プラットフォーム選択（Uber Eats / 出前館 / menu / Wolt / その他）
   - 天候（晴れ/曇り/雨/大雨：ワンタップ手動選択 ＋ Open-Meteo API連携による現在地天気自動取得ボタン付き）
   - 主要稼働エリア、自由メモ（最大500文字）
2. **稼ぎ分析ダッシュボード**
   - **核心指標のリアルタイム表示**: 平均時給（円/h）、件単価（円/件）、km単価（円/km）
   - **多角的な集計分析**: 曜日別・時間帯別・天候別の平均時給・売上比較（Recharts表示）
   - **確定申告・経費補助機能**: 月別/年別の売上累計、走行距離累計、ガソリン代・減価償却費等の経費試算
   - **データ管理機能**: 確定申告用CSV/JSONエクスポート、日報履歴の編集・削除
3. **Google Maps エリアマップ表示**
   - 登録された稼働実績データを地図上にピン表示し、高効率エリアを視覚化（APIキー未設定時はプレースホルダーマップ表示）

### 【将来フェーズ（案1・案2の統合拡張）】
- **フェーズ2（案1統合）**: オファー受諾即時判定シミュレーター（1km単価・推定所要時間時給換算）
- **フェーズ3（案2統合）**: 店舗別待ち時間・マンション等ドロップ注意メモピンマップ

---

## 4. 非機能要件
- **画面表示・UI**: iPhoneサイズ（390×844px基準）に最適化したPWA対応（全画面表示、タテ持ち片手操作）。
- **データ保存**: Supabase（クラウドPostgreSQL）により永続化。未設定時はLocalStorageフォールバック。
- **拡張性・保守性**: React + Vite によるコンポーネント指向設計。案1・案2をタブ切り替えで容易に追加可能。
